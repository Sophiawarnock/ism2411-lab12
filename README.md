
# ISM2411 Lab 12 - CSV Processing

## Description
This project uses Python to read, process, clean, and summarize sales data from a CSV file.

## Exercises Completed
1. Python and CSV reflections
2. Read and print CSV rows
3. Skip the CSV header
4. Calculate sales totals and revenue
5. Filter sales and write cleaned data
6. Use csv.DictReader
7. Create a sales summary by product
8. Append results to a run log

## Files
- csv_practice.py: Main Python program
- data/sales.csv: Original sales data
- data/cleaned.csv: Cleaned sales data
- data/run_log.txt: Program run history

## How to Run
Run the following command:

python3 csv_practice.py
